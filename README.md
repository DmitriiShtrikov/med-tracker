# Домашняя аптечка онлайн (Fullstack проект)

## Назначение приложения
Приложение предназначено для ведения учёта домашних лекарств. Оно позволяет отслеживать сроки годности, количество и категории медикаментов, а также подбирать подходящие препараты по симптому. Дополнительно приложение помогает проверить комплектность экстренного набора и найти организации для передачи ненужных, но годных лекарств.

## Основные пользовательские сценарии
1. **Авторизация:** Регистрация и вход в систему (JWT-токены, защита данных).
2. **Обзор:** Просмотр сводной статистики (всего упаковок, истекающие, просроченные) и списка лекарств, требующих внимания.
3. **Аптечка:** Просмотр полного списка лекарств (только своих), поиск, фильтрация и удаление.
4. **Добавление и Редактирование:** Создание/изменение записей с выбором категории и симптома из справочников БД.
5. **Подбор:** Выбор недуга из базы для получения списка подходящих лекарств из своей аптечки.
6. **Экстренный набор:** Проверка наличия обязательного минимума препаратов.
7. **Приюты:** Просмотр информации о благотворительных организациях.

## Стек технологий
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, React Router v6, Axios
- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic, Python-JOSE (JWT), Passlib (bcrypt)
- **База данных:** PostgreSQL
- **Контроль версий:** Git

## Настройка и запуск Backend

### 1. Требования
- Установленный Python (3.9+)
- Установленный PostgreSQL (порт 5433)
- Созданная база данных `med_tracker`

### 2. Установка зависимостей
```bash
cd backend
python -m venv venv
venv\Scripts\activate  # Для Windows
pip install -r requirements.txt
```

### 3. Настройка окружения
Создайте файл `.env` в папке `backend` и укажите свой пароль от PostgreSQL:
```env
DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5433/med_tracker
```

### 4. Запуск сервера
```bash
uvicorn app.main:app --reload
```
API доступно по адресу: `http://localhost:8000`
Документация Swagger UI: `http://localhost:8000/docs`

## Настройка и запуск Frontend

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск
```bash
npm run dev
```
Приложение доступно по адресу: `http://localhost:5173`
